# MedGuide AI — Environment Reference

**Status:** Current as of Day 3. Update this file whenever a new environment variable, tool, or config file is introduced.

## Environment Variables

| Variable | Where it's used | Required? | Notes |
|---|---|---|---|
| `GROQ_API_KEY` | `agent/graph.py` (Day 6), loaded via `python-dotenv` | Yes | Stored in local `.env` (gitignored). On Streamlit Cloud (Day 9), stored in Streamlit's Secrets manager instead — `agent/graph.py` will be written to check both sources. |

No other environment variables are required for v1.0 — there's no database connection string, no auth secret, no third-party API beyond Groq, per the locked architecture (no user accounts, no separate backend).

## No Database Connection String

Per `SCHEMA.md` (Day 2), this project uses Chroma (embedded, file-based) and flat CSVs — there is no external database, so there is no connection string to configure. `chroma_store/` is simply a local folder generated by `ingestion/build_index.py` on Day 4.

## No Authentication Configuration

Per the PRD's explicit out-of-scope list, there are no user accounts, so there are no auth secrets, tokens, or session-management configuration to set up.
